# CodeBloom Android Releases

This repository publishes installable preview builds of CodeBloom for Android.

## Download

Open the [Releases page](https://github.com/Vindhesh/apkReleases/releases) and download the phone-compatible APK asset from the latest release. The `phone` APK supports ARM64 and ARMv7 Android phones. Preview builds are distributed for testing and are not published through Google Play.

## Install

Download the APK on your Android phone, open it, and allow installation from your browser or file manager if Android asks. You can turn that permission off again after installing.
